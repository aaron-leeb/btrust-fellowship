One of the Bitcoin Core pull requests (PR) I reviewed recently was https://github.com/bitcoin/bitcoin/pull/36128, which adds Bitcoin script test cases to the codebase to kill mutants. If you're anything like I was prior to understanding the context of the PR, you're probably wondering what a mutant is and why we're killing them. For those that are fans of Marvel, no this isn't X-Men. Mutants are essentially a copy of the source code that contains a small, deliberate change used to test the quality and coverage of your test suite. For anyone familiar with software testing that probably makes sense. If not, bare with me as I explain in more depth how I verified the mutants were dead.
