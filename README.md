# BTrust Fellowship - Technical Articles

This repository contains technical articles written while completing a 12-week fellowship with [BTrust](https://www.btrust.tech/), a program designed to prepare developers to contribute to Bitcoin open-source software.

These articles are exploratory and reflect my personal learning journey, technical research, and evolving understanding of Bitcoin's protocols and software. They document concepts I found interesting, questions I explored, and practical experiences I gained while becoming more involved in Bitcoin open-source development.

Rather than serving as comprehensive technical guides, these articles are intended to share what I've learned and hopefully provide useful insights for others interested in understanding Bitcoin at a deeper technical level.

## Articles

- BTrust Fellowship — Weeks 1 & 2 — Exploring Bitcoin's origins, SegWit, mining, block propagation, and the peer-to-peer network.
    
- Separating Your Private Keys from Your Lightning Node Should Be the Standard — Examining Lightning Network security and the benefits of validating Lightning signers.
    
- Compact Block Filters (BIP 158) — Understanding privacy-preserving transaction discovery for lightweight Bitcoin clients and its implementation in Bitcoin Core.
    
- How I Verified the Mutants Were Dead — Documenting my experience reviewing a Bitcoin Core pull request and validating test coverage through mutation testing.
    

## A Note on the Content

These articles represent my understanding at the time they were written. As I continue learning and contributing to Bitcoin open-source projects, my understanding and perspectives may evolve.

Feedback, corrections, and technical discussions are always welcome.
